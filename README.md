
# A CIDADE SEM ROSTO

Jogo 3D de suspense, exploração e mistério.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Three.js

## Como jogar

1. Abra o jogo pelo GitHub Pages.
2. Clique em INICIAR INVESTIGAÇÃO.
3. Clique na tela para ativar a câmera.
4. Use W, A, S e D para movimentar.
5. Use o mouse para olhar ao redor.
6. Pressione ESC para pausar.

## Estrutura

- index.html: estrutura principal.
- style.css: identidade visual.
- js/main.js: inicialização do jogo.
- js/world.js: construção da cidade.
- js/player.js: personagem.
- js/controls.js: movimentação.
- js/interface.js: interface.
- js/audio.js: áudio.
- js/missions.js: missões.
- js/inventory.js: inventário.
